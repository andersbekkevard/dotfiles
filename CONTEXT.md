# Fable Counsel

The language for independent second-model judgment in the agent fleet. Fable
supplies counsel while Sol retains ownership of the decision.

## Language

**Counsel**:
Considered judgment supplied by Fable to Sol without transferring decision
ownership.

**Propose**:
The counsel branch for an open decision. Fable forms an independent direction
from user intent, constraints, agreed premises, and evidence.
_Avoid_: Cold read, frame

**Challenge**:
The counsel branch for a formed direction. Fable tests the direction and its
rationale against omissions, alternatives, and evidence, and may affirm it.
_Avoid_: Plan counsel, critique
