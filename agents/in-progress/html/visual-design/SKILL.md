# Visual design

Use a quiet visual language. Make the artifact easy to enter, scan, understand,
and trust. The design should clarify the content without announcing itself.

This is a preference skill. It owns the general visual language, while
medium-specific skills own production details. For charts and data displays,
also use `tufte-viz` when available.

## Principles

### Begin with the reading task

Design around what the reader needs to notice, compare, decide, or do. The
opening view should establish the subject, relevant context, and primary point
without requiring prior conversation.

### Build hierarchy before decoration

Create order with position, scale, spacing, alignment, and typographic weight.
Use boxes, borders, fills, and shadows only when they explain grouping, state,
or depth. One element should lead each page or screen; supporting material
should visibly recede.

### Keep the canvas quiet

Favor light neutral surfaces, dark neutral text, generous margins, and a small
number of visual levels. Let whitespace group related material and separate
changes in subject. Use density where the content benefits from comparison,
not to fill space.

### Treat color as language

Use a compact palette with stable roles: primary ink, muted information,
structure, emphasis, positive, negative, and warning. Reserve the strongest
colors for meaning. Make opposing states distinct in hue or luminance, not only
in saturation, and pair color with labels, position, or shape when the meaning
must survive grayscale or color-vision differences.

### Make information direct

Put labels beside what they describe. Write titles that identify the subject,
measure, period, or state plainly. Show the dates, units, basis, source, and
uncertainty needed to interpret the content. Prefer a clear sentence over a
clever heading.

### Let the content carry the visual interest

Use the real words, numbers, images, and relationships as the main graphic
material. Remove ornamental chrome, repeated legends, generic icons, and empty
containers. Preserve explanatory context even when it costs a little ink.

### Make density breathable

Keep related information close enough to compare, then use spacing to mark a
real change in level or topic. Avoid both cramped dashboards and sparse pages
that force the reader to hunt across empty space. A compact, well-grouped page
can feel calmer than a large collection of cards.

### Maintain one grammar across the artifact

Assign consistent roles to type, color, spacing, rules, and components. Repeat
those roles rather than individual layouts. Allow the medium to change the
expression: a printed brief, interactive dashboard, slide, and diagram may use
different compositions while still feeling related.

### Earn every exception

Break the system when the content needs it, not for variety. A strong color,
different type scale, dense panel, or dramatic image should signal a genuine
change in importance, state, or reading mode.

## Working method

1. Inspect the actual content, target medium, and any established visual
   conventions before choosing a treatment.
2. State the reading task and rank the content into primary, supporting, and
   reference levels.
3. Define a small visual grammar for the artifact: type roles, color roles,
   spacing rhythm, alignment, and surface treatment.
4. Compose the hierarchy in the target medium. Add decoration only when the
   structure still needs help.
5. Render the real artifact at its intended size. Inspect the opening view,
   scan path, labels, contrast, overflow, and print or small-screen behavior
   when relevant.
6. Remove anything that competes with the content or repeats a meaning already
   expressed more directly.

## Completion bar

Before delivery, verify that:

- the opening view makes sense without chat context;
- the visual priority is obvious at a glance;
- color roles are consistent and opposing states are easy to distinguish;
- text, units, dates, sources, and uncertainty remain legible;
- repeated components behave as one system;
- the actual rendered artifact, not only its source, has been inspected.
