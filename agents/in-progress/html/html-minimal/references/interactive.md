# Interactive decisions

Use interaction when Anders should make a decision in the artifact: clicking,
selection, multi-selection, multiple choice, triage, or tuning. Make it a
delightful user journey rather than turning every report into an application.

Let Anders copy the resulting decision as concise Markdown, JSON, or another
more token-efficient format and paste it back to the agent. Keep the copied
output faithful to the visible state and verify it before handoff.
