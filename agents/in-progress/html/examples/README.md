# HTML examples

This folder preserves exact HTML artifacts Anders liked while `/html` is still
evolving. The reports are empirical evidence, not templates or settled rules.
Each file has one entry below recording the context, the specific qualities
Anders liked, a possible reusable lesson, and what should not yet be
generalized.

Name artifacts with a stable two-digit sequence and a descriptive slug:
`NN-html-name.html`.

## 01 — HTML skill source audit

- **Artifact:** [01-html-skill-source-audit.html](01-html-skill-source-audit.html)
- **Context:** An audit reproduced a large corpus of skill and reference files,
  then highlighted the lines concerned with HTML and visual behavior.
- **Anders liked:** Collapsible files provided details on demand. “Show
  highlighted only” made the relevant subset immediately inspectable without
  removing access to the complete source. The visual language was clear, and
  the legend explained the semantic meaning of every highlight color.
- **Possible lesson:** For a large text corpus—especially prompt, instruction,
  transcript, policy, or source audits—start with an overview and semantic
  legend, preserve the complete material in collapsible sections, and offer a
  focused-subset filter for the active question.
- **Do not generalize yet:** Most reports do not need corpus-scale interaction.
  A focus filter is useful when the full source remains materially relevant;
  it should not hide evidence or caveats the reader needs to judge the claim.
